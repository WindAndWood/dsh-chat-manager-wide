# Security policy

## Supported version

Security fixes are provided for the latest release.

## Report a vulnerability

Report privately through GitHub's **Security → Report a vulnerability** form on
[WindAndWood/dsh-chat-manager-wide](https://github.com/WindAndWood/dsh-chat-manager-wide/security/advisories/new),
or through the maintainer contact shown on the
[`dsh-chat-manager-wide` npm page](https://www.npmjs.com/package/dsh-chat-manager-wide) if that form is
unavailable. Please do not put session contents, local paths, profile files, or a working destructive
proof of concept in a public place.

Include the DSH version, plugin version, storage backend, operating system, and
the smallest redacted reproduction you can provide. Do not attach real session
logs.
