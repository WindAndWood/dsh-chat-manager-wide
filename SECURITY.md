# Security policy

## Supported version

Security fixes are provided for the latest release.

## Report a vulnerability

This fork has no public source repository yet, so it exposes no **Security → Report a vulnerability**
form. Report privately through the maintainer contact shown on the
[`dsh-chat-manager-wide` npm page](https://www.npmjs.com/package/dsh-chat-manager-wide). Please do not
put session contents, local paths, profile files, or a working destructive proof of concept in a public
place.

Include the DSH version, plugin version, storage backend, operating system, and
the smallest redacted reproduction you can provide. Do not attach real session
logs.
